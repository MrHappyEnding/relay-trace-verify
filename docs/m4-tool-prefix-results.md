## 这轮说明了什么

**目前唯一未完成的前缀是 sympy-13091。** 原生继续把其结果从 0 变成 1；两个异构接力
分支都没有做到。因此，本轮有原生继续完成未完成修复的证据，异构接力救回未完成任务为
0/1，不能把另外三题原本已通过的前缀算作救回成功。

`sympy-15599` 的工作区接力引入了回归：它修改了 `sympy/core/mod.py` 中的分配条件，
独立测试从前缀的 1 变成 0；原生继续与摘要接力保留相同 tracked patch 并通过。
这说明交接后的 agent 也可能破坏已有成果。具体原因与更好的防回归策略仍需进一步分析。

只有 **4 个独立任务**，不是 16 个独立样本。主比较“摘要接力减原生继续”为 -25 个百分点，
按任务配对 bootstrap 的探索性 95% 区间为 [-75, 0] 个百分点。这个开发集结果不支持总体
优越性结论；模型与 scaffold 同时变化，订阅成本未知，也不能声称端到端成本更低。
统计工具保留全部成功、失败及关联记录，没有按结果排除样本。

## 复现事后前缀诊断

新增 [m4_prefix_diagnostics.py](../scripts/m4_prefix_diagnostics.py) 先验证全部输入运行的冻结
身份、四条观察收集与资源释放，再从 manifest 校验后的 checkpoint 恢复工作区，并调用同一
断网独立 verifier。它不读模型凭据、不提交新 Trial、不反馈测试结果；输出必须使用新目录。
已验证未完成的整轮会在启动任何容器前被拒绝。实际四个诊断均通过完整性检查，源工作区不变。

```bash
.venv/bin/python scripts/m4_prefix_diagnostics.py \
  --roots work/m4-data/tool-prefix-round-1/sympy__sympy-22914 \
          work/m4-data/tool-prefix-round-1/sympy__sympy-15599 \
          work/m4-data/tool-prefix-round-1/sympy__sympy-13091 \
          work/m4-data/tool-prefix-round-1/scikit-learn__scikit-learn-9288 \
  --output work/m4-prefix-diagnostics-new
```

命令需要本机已保留的运行产物、任务包和镜像；该脚本验证调用者声明的整轮 roots，不会推断其他并行实验。
运行设置、来源文件 SHA、逐阶段用量、配对统计和诊断结果见证据文件。过去三轮自然结束试验保持独立。
