## Commands

From the repository root, using Python 3.12+:

```bash
uv sync --python 3.13 --locked --group harbor --dev
uv run --no-sync rtv harbor-doctor
```

Core RTV still supports Python 3.11. The optional `harbor` group pins Harbor 0.24.0,
with transitive dependencies in uv.lock. Plain `uv sync` may remove this optional
group; include it again before integration work. `harbor-doctor` checks versions,
the Harbor task schema, a Linux Docker daemon, and Compose. It starts no containers,
pulls no images, and calls no models. Failed requirements produce JSON and a nonzero exit.

Once Docker is available:

```bash
uv run --no-sync rtv harbor-smoke --output work/m0-smoke-1
```

The first run downloads the digest-pinned Python base image and creates two short-lived
CPU task environments. Harbor adds network-control sidecars and builds their image;
the report records every container image ID. The sidecar's upstream base image is
not yet pinned by digest. Only the trusted `examples/tasks/positive-sum` fixture is supported;
use `--task` to locate it when running outside the repository root. Output must not
already exist. No GPU or model credentials are attached. Runtime networking is
`no-network`; pulling the base image during build needs network access.

## Protocol

1. Load the Harbor `Task` and create the source `DockerEnvironment`.
2. A controlled script implements positive filtering but leaves empty input broken.
3. Locate the source task container using this run's unique Compose project and `main` service, stop it, verify it is
   stopped, then export `/workspace`.
4. Commit an RTV local file checkpoint and restore verified files to a fresh host directory.
5. Use the exact source image ID as the target prebuilt image, restore files, then
   compare paths, contents, and permission hashes.
6. Harbor's `Verifier` must reject the partial solution, then accept the completed script.
7. Confirm target writes did not change the source, delete the environments created
   by this run, and check for remaining containers.

Stopping the whole source container is this probe's file-quiescence boundary;
process memory is lost. This does not prove arbitrary agents can preserve native
sessions at that boundary. Harbor 0.24.0 `stop(delete=False)` invokes Compose down,
so the probe uses Docker stop before export and Harbor cleanup afterward.

## Artifacts and boundaries

- `report.json`: dependency/task digests, image ID, execution identities, checkpoint,
  verification, and cleanup status.
- `events.jsonl`: local control events associated with execution and checkpoint IDs.
- `exported/`, `restored/`, `roundtrip/`: files used for transfer validation.
- `checkpoints/`: snapshots; `source/` and `target/`: Harbor logs.

Reports use `mode: harbor-scripted-smoke` and `model_calls: 0`. This is a transfer
and verification prototype, with no native sessions, ATIF, budget ledger, durable
recovery, or model-effectiveness evidence. Verification runs in the target container,
not a separate hidden-test service. Cleanup errors fail the report and identify the
session; there is no global prune. Build-cache images may remain; unrelated resources
are not deleted.

## Current evidence

The [real-container report from 2026-10-08](evidence/m0-docker-arm64-20261008.json)
records successful file recovery, matching source/target image IDs, a verifier
reward change from 0 to 1, no cleanup errors, and zero model calls. Local artifacts
are in `work/m0-docker-repair-20261008-2/`, produced by:

```bash
HARBOR_TELEMETRY=0 uv run --no-sync rtv harbor-smoke --output work/m0-docker-repair-20261008-2
```

Use a fresh output directory when repeating the run. Real execution exposed two
integration gaps: rebuilding the target changed its image ID, so it now reuses the
exact source image; constructing DockerEnvironment directly omits Trial's log mounts,
so each environment now explicitly mounts its own agent/verifier output directories.
This evidence covers only the trusted scripted fixture. Real-agent, session, and
budget capabilities remain outside completed M0 acceptance.

Opt into real-container tests with:

```bash
RTV_RUN_DOCKER=1 uv run --no-sync pytest -m integration -q
```

Normal tests skip this test; a skip is not container evidence. Run `harbor-doctor`
