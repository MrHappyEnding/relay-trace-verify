    02 / UNDER THE HOOD
    Continuity is a system property.
    A task outlives any single execution. 
    Each boundary has an explicit contract.
    
    
    01
    Relay Keep the work.
    Seal a quiescent workspace, attach the selected context, and restore into an independent execution. Native continuation and cross-agent handoff have distinct contracts.
    02
    Trace Keep the history.
    Connect tasks, attempts, executions and checkpoints. Preserve ownership, provenance and cost records across every transition.
    03
    Verify Check the result.
    Run the task verifier in a separate environment. Record the outcome alongside the execution, with explicit boundaries and inspectable artifacts.
